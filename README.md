# SAFEWAY AUTO – Website thương mại điện tử

Website tĩnh giới thiệu và nhận yêu cầu đặt hàng cho sản phẩm thiết bị cảnh báo khoảng cách an toàn ô tô.

## Chạy trên máy
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub, ví dụ: `safeway-auto`
2. Upload `index.html`, `style.css`, `script.js`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`.
6. Save và chờ GitHub cấp đường dẫn website.
